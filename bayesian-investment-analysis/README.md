## Bayesian Investment Analysis

This project implements a Bayesian Network for assessing sustainable investment decisions under uncertainty. Using `pgmpy`, it models probabilistic relationships between ESG, financial risk, and external policy interventions.

### Key features:
- Interactive Bayesian model built from domain knowledge and data
- Simulated scenarios to analyse sustainability outcomes
- Useful for policy planners and investors in green finance
