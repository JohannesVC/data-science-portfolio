## Mapping Corporate Ethics with NLP

Clustered the mission statements of UK companies using unsupervised NLP on Common Crawl data. Focus on value alignment and ethical language in business.

### Key features:
- TF-IDF and topic modelling (LDA)
- Cluster visualisation using PCA and t-SNE
- Large-scale data handling via PySpark
