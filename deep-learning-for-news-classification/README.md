
## Systematic News Classification with Deep Learning

This project benchmarks several deep learning architectures (LSTM, GRU, CNN, Transformer) for topic classification of news articles.

### Key features:
- Structured model comparison with reproducible pipelines
- Performance metrics across categories
- Built using Keras 3.8 and TensorFlow 2.17
