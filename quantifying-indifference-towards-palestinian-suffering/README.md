## Quantifying Indifference Towards Palestinian Suffering across UK News Sources

Investigates differential media attention to Palestinian casualties using UK news data. Applies text classification, NER, and statistical analysis.

### Key features:
- Named Entity Recognition and topic modelling
- Human-in-the-loop coding of articles
- Geopolitical media framing analysis
