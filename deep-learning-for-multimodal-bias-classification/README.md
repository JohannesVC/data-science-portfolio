
## Multimodal Bias Classification in News

A deep-learning project combining headlines, and images to predict political bias in news articles. Uses hybrid CNN + text architecture in Keras 3.8.

### Key features:
- Multi-input model combining structured and unstructured data
- Focus on political bias detection
- Built using Keras 3.8 and TensorFlow 2.17
